# 카드 부정사용 현장 판단

지구대·파출소 경찰관이 타인 카드·계좌·간편결제 부정사용 112 신고 현장에서 **어떤 법이 적용되는지** 바로 확인하는 웹앱입니다.

- 사용 주소: https://bandit1397.github.io/Fraudulent-Card-Use/
- 휴대전화에서 열고 "홈 화면에 추가"하면 앱처럼 쓸 수 있고, 한 번 연 뒤에는 인터넷이 없어도 동작합니다.
- 입력한 내용은 기기 밖으로 전송·저장되지 않습니다 (서버·로그·분석도구 없음).

> 현장 참고용입니다. 최종 죄명과 적용법조는 수사팀과 검사 지휘에 따릅니다.

## 기능

| 메뉴 | 다루는 사건 |
|---|---|
| 카드·계좌 무단사용 | 신용·체크·현금카드, 선불·교통카드, 카드정보, 타인 휴대전화(간편결제·뱅킹앱), 위조카드, 명의도용 발급카드를 습득·절취·강취·기망·공갈·보관 중 사용 |
| 대포통장·카드 | 체크카드·통장·OTP 등 접근매체와 신용카드, 계좌정보의 양도·대여·보관·전달·알선 |
| 잘못 들어온 돈 | 착오송금 인출, 보이스피싱 피해금이 들어온 계좌 명의인의 인출 |
| 법령·판례 | 원문 대조한 조문과 판례 검색 |

결과 화면은 세 단계입니다.

1. **30초 요약** — 적용 죄명과 경합 관계
2. **단계별 검토** — 취득·사용 행위마다 적용 / 검토 / 불성립과 이유, 근거 판례(누르면 요지와 원문 링크)
3. **현장 조치 · 질문 목록 · 범죄사실 초안** — 선택한 수단·취득 경위·사용 행위·결과·친족 관계에 맞춰 항목이 바뀜. 입력칸을 채우면 문안이 완성되고 복사할 수 있음

## 판단 기준

- 조문: 국가법령정보센터 현행 원문 (2026-10-14 대조)
- 판례: 대법원 판례 23건 원문 대조
- 판례가 없거나 견해가 갈리는 쟁점은 **'검토'**로 표시하고 이유를 적었습니다. 목록은 [docs/검증기록.md](docs/검증기록.md)에 있습니다.
- 범행 시기에 따라 달라지는 사항(2025. 12. 23. 사기 법정형 상향, 2024. 6. 27. 이후 친족상도례 친고죄화)을 반영했습니다.

## 구조

```
index.html            화면
css/style.css
js/engine.js          판단 엔진 (화면과 분리 — Node 테스트에서 그대로 실행)
js/app.js             화면 동작
data/laws.js          조문 · 법정형 · 미수 처벌 여부
data/precedents.js    판례 요지 · 원문 링크
data/guides.js        현장 조치 · 증거 · 질문 · 범죄사실 템플릿
tests/cases.js        판례 사안 회귀 테스트
tests/run.js          테스트 실행기 (모든 선택지 조합 검사 포함)
tools/*.py            법령·판례 원문 내려받기 · 검색 스크립트
docs/검증기록.md       검증 내역과 미확인 쟁점
sw.js, manifest.webmanifest   오프라인 설치
```

## 테스트

```bash
node tests/run.js
```

판례 사안 29건이 판례와 같은 결론을 내는지, 화면에서 고를 수 있는 모든 조합(3,330건)이 오류 없이 결과를 내고 존재하는 조문·판례만 참조하는지 확인합니다. 또 모든 조합(428건)에서 적용 죄명마다 범죄사실 문안이 있는지, 조건(강취·친족·ATM·온라인·승인 거절·휴대전화 등)이 바뀌면 현장 조치·질문도 바뀌는지 검사합니다.

## 수정하는 방법

- 법이 바뀌면: `data/laws.js` 수정 → `meta.verified` 날짜 변경 → `sw.js` 의 `VERSION` 올리기 → `node tests/run.js`
- 판례 추가: `data/precedents.js` 에 추가 → 엔진 규칙 반영 → `tests/cases.js` 에 사안 추가
- 현장 조치·질문 수정: `data/guides.js` 의 `ACTIONS`, `Q_VICTIM`, `Q_SUSPECT` (각 항목의 `when` 이 표시 조건)
- 범죄사실 문안 수정: `data/guides.js` 의 `FACTS` (`조항:사용유형` → `조항:상황` → `조항` 순서로 찾음)
