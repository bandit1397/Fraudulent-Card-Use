카드 부정사용 현장 판단

현장 참고용 (사용방법)
  1. 메뉴 선택 — 위쪽 탭에서 사건 유형(카드·계좌 무단사용, 대포통장·카드, 잘못 들어온 돈, 편의시설·무임승차)을 고릅니다.
  2. 사실관계 입력 — 1~4 단계 제목을 누르면 펼쳐집니다. 항목을 고르면 결과에 바로 반영되고 그 단계는 다시 접혀, 제목 아래에 고른 내용만 표시됩니다. 한 단계에 질문이 여러 개(예: 4단계의 관계·시기)이면 제목을 다시 눌러 펼친 뒤 다음 질문을 고릅니다. 사용 행위가 여러 번이면 3단계에서 ‘+ 사용 행위 추가’를 누릅니다.
  3. 판단 결과 확인 — 입력하는 즉시 아래 ‘30초 요약’에 적용 죄명이 나타납니다. (검토) 표시는 판례가 없거나 사실관계에 따라 결론이 달라지는 죄명입니다.
  4. 세부 내용 — 단계별 검토, 현장 조치·증거 확보, 질문 목록, 범죄사실 초안은 제목을 누르면 펼쳐집니다. 요약의 죄명을 누르면 해당 범죄사실 초안으로, 법조문을 누르면 조문 전문으로 이동합니다.
  5. 범죄사실 초안 — 일시·장소·피해자 등 빈칸을 채운 뒤 복사해 사용합니다.

최종 죄명·적용법조는 관계 부서와 협의가 필요합니다. 입력한 내용은 이 기기 밖으로 전송·저장되지 않습니다.
