### 확인하면서 바로잡은 사항

- **사기·컴퓨터등사용사기 법정형**: 2025. 12. 23. 개정으로 '20년 이하 징역 또는 5천만원 이하 벌금'으로 상향(공포일 시행). 그 전 범행은 '10년 이하 / 2천만원 이하'가 적용되므로 앱에서 범행 시기를 묻는다.
- **친족상도례(형법 제328조)**: 2025. 12. 31. 개정. 친족이면 형 면제가 아니라 **고소가 있어야 공소제기**(친고죄). 부칙 제2조에 따라 2024. 6. 27. 이후 범행부터 적용. 그 전 범행은 구 제328조 제1항(형 면제)이 적용된다(2024도19846: 헌법불합치결정의 소급효 없음).
- **여신전문금융업법 제70조 제6항**: 미수범 처벌은 제1항 제1호·제2호(위조·변조, 위조카드 사용)만. 분실·도난 카드 사용(제3호)과 강취 등 취득 카드 사용(제4호)은 미수를 처벌하지 않는다.
- **초안의 판례번호 오류**: 설계 단계에서 "카드 일시사용 후 반환" 판례를 98도3329로 적었으나 실제로는 무인단속 사진 증거능력 판례였다. 올바른 판례는 **99도857**.

## 다시 검증하는 방법

```bash
# 법령 원문 받기 → 조문 출력
python tools/fetch_law.py 저장폴더 "형법" "여신전문금융업법" "전자금융거래법"
python tools/article.py 저장폴더/여신전문금융업법.xml 70

# 판례 원문 확인 · 새 판례 검색
python tools/fetch_prec.py 저장폴더 2003도3977
python tools/search_prec.py "교통카드 부정사용"

# 판단 엔진 회귀 테스트 (판례 사안 + 모든 선택지 조합)
node tests/run.js
```

법령이 바뀌면 `data/laws.js` 의 해당 조문과 `meta.verified` 날짜를 고치고, `sw.js` 의 `VERSION` 을 올린 뒤 테스트를 돌린다. 새 판례를 반영하면 `data/precedents.js` 에 추가하고 `tests/cases.js` 에 그 사안을 테스트로 넣는다.
