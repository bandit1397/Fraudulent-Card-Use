  - 위조카드로 무인 단말기 결제 · 현금서비스를 시도하다 실패한 경우: '미수 불처벌' → 위조카드 사용 미수 **처벌** (여신전문금융업법 제70조 제6항은 제1호 · 제2호 미수를 처벌)

  - 신용카드 질권(담보): '검토' → **불성립** (제70조 제4항 제3호는 양도 · 양수만 처벌)

## '검토' 표시 기준

'검토'는 두 가지 이유로 나뉘며 화면에 함께 표시한다.

- **대법원 판례 없음**: 이 쟁점을 직접 판단한 대법원 판례를 찾지 못한 경우 (하급심 · 유사 판례만 있는 경우 포함)
- **사실관계 확인 필요**: 판례 법리는 있으나 사실(영득 의사, 범죄 이용 인식, 카드를 건넨 경위, 실행 착수 등)에 따라 결론이 갈리는 경우

## 다시 검증하는 방법

```bash
# 법령 원문 받기 → 조문 출력
python tools/fetch_law.py 저장폴더 "형법" "여신전문금융업법" "전자금융거래법"
python tools/article.py 저장폴더/여신전문금융업법.xml 70

# 판례 원문 확인 · 새 판례 검색
python tools/fetch_prec.py 저장폴더 2003도3977
python tools/search_prec.py "교통카드 부정사용"

# 조문 전문(data/law_texts.js) 다시 만들기 — 원문에서 그대로 추출
python tools/build_law_texts.py 저장폴더

# 앱 조문 데이터 전체를 원문과 자동 대조
python tools/verify_laws.py 저장폴더

# 판단 엔진 회귀 테스트 (판례 사안 + 모든 선택지 조합)
node tests/run.js
```

법령이 바뀌면 `data/laws.js` 의 해당 조문과 `meta.verified` 날짜를 고치고, `sw.js` 의 `VERSION` 을 올린 뒤 테스트를 돌린다. 새 판례를 반영하면 `data/precedents.js` 에 추가하고 `tests/cases.js` 에 그 사안을 테스트로 넣는다.
